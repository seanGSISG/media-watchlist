# Media Watchlist

Personal tracker for movies, TV shows, and audiobooks I want to remember to watch or listen to.

## Categories

| Category | List |
|----------|------|
| Movies | [movies/](movies/watchlist.md) |
| TV Shows | [shows/](shows/watchlist.md) |
| Audiobooks | [audiobooks/](audiobooks/watchlist.md) |

## How It Works

Each category has a markdown table tracking titles with relevant metadata (links, year, genre, status). Entries are added with a date stamp and marked as watched/listening/completed over time.
